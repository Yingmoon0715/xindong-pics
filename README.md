# 心动小手机图床

底图/图标/组件图统一存这里，手机端通过 jsDelivr 引用（国内可直连）。

## 引用格式

https://cdn.jsdelivr.net/gh/yueyinglove/xindong-pics@main/路径

例：底图 → https://cdn.jsdelivr.net/gh/yueyinglove/xindong-pics@main/bg/phone-bg-main.webp

## 目录

- bg/ 底图类（手机背景主图/备用/无水印）
- icon/ 图标类（应用点开图/组件图标）
- misc/ 弹窗底图等
- docs/ 设计参考图

## 加图方法

1. 手机/电脑浏览器打开本仓库网页 → Add file → Upload files → 拖图 → Commit（直接传 jpg/png 也行，前端都能用）
2. 或让 AI 用服务器上的令牌代传（令牌在 0.导航/3.密钥/2.大厂/github_token.txt）

## 压缩约定

照片类 WebP q90（视觉无差异），图标截图类无损。手机端「图库」应用会自动列出本仓库全部图片。
